# 📝 Smart To-Do (Java App)

A **simple yet powerful To-Do List application** built with **Java** to help you organize tasks, boost productivity, and never miss deadlines.  
Clean design, easy to use, and perfect for managing daily goals!

---

## ✨ Features

- ✅ Add, edit, and delete tasks  
- 📌 Mark tasks as **completed** or **pending**  
- 🔍 Search and filter tasks easily  
- 💾 Persistent storage (tasks are saved automatically)  
- 🎨 Simple & intuitive user interface  
- ⚡ Lightweight and fast  

🛠️ Tech Stack

Language: Java
Framework: Springboot
Storage: MySQL
